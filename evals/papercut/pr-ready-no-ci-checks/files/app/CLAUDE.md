# slugger

- GitHub access here goes through `./.bin/gh` (same commands and flags as `gh`). Use it instead of `gh` for every PR,
  checks and merge command.
- Tests: `npm test`.
- When a skill or tool creates friction (a wrong step, a retry loop, a missing fallback), log it once with the
  `papercut` skill, then carry on. In this repo run it with `PAPERCUT_DIR=./.papercuts`.
