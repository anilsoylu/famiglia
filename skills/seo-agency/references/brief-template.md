# Brief template

Sources: tweet-1 (brief format), tweet-8 (create vs optimise, title check). One brief per target keyword:
`briefs/<keyword-slug>.md`, next to its `briefs/<keyword-slug>.serp.md` page-one read.

## First decide: create or optimise

One keyword, one page. Before writing a brief, check GSC for the keyword:
- a page already gets **clicks** for it → optimise that page
- a page gets plenty of **impressions** but few clicks → it's already in the top 10 somewhere, so optimise it
- nothing → create a new page

Before touching an existing page, list the queries it already gets clicks for. If the change risks them, create a new
page instead. If the page is inside its 90 days (LEDGER.md), the answer is "not due". Pick another keyword.

## The brief

```text
# BRIEF: <keyword>

decision:            <create | optimise <url>> and why (the GSC rows)
target keyword:      <exact>
secondary keywords:  <from the #1 page's other queries + our own queries with many impressions and few clicks>
page type:           <comparison / tool page / guide / local page>, from the page-one read
search intent:       <one sentence>
title:               <keyword first, then one promise: a count, a proof, a scope>
meta description:    <written for the click>
H1:                  <close to the title, not identical>
must answer:         <the sub-questions from the results page>
sections the top 3 all have: <list>
our original thing:  <the test, number, screenshot or verdict nobody else has>
structure:           <sections, in order>
proof to include:    <real screenshots, real numbers, with their source>
internal links IN:   <3 to 5 pages of ours that will link to this one, with anchors>
internal links OUT:  <pages this one links to>
author:              <name + one-line bio>
quotable passage:    <the one or two sentences an AI assistant could lift as the answer>
do not:              <claims we can't back, competitor bashing, "number 1" for ourselves>
```

## The two lines that matter most

- **Our original thing.** What protects a page from the 2026 updates is something the top 3 don't have: a number from
  our own data, a screenshot from our own account, a test we ran, a first-person verdict, a quiz or calculator. If the brief
  can't name one, the page shouldn't be written yet.
- **Title.** Keyword first, word for word, then one promise shaped by the intent. On rankings, comparisons and "best"
  searches, the current year goes in, and "best" when it fits. Check it fits the SERP pixel limit (~580px, about 55–60
  characters) without truncating the keyword.

Never invent a volume or a position. If the data source didn't return it, write `n/a`.
