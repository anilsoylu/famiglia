# awesome-prompts

`skills/almost-paid` is copied unchanged from https://github.com/nestyme/awesome-prompts (pinned in `vendor.json`).

That repository has no license file. Its author shared the skill publicly for others to use, so famiglia bundles it with
credit. The author keeps all rights to it: famiglia's Apache-2.0 license does not cover it. If the author asks, we remove
it.

The skill calls `tools/cohort_value.py` from the same repository, which is not bundled. Get it from the source repo.
